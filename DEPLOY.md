# Forma: запуск и размещение

## На компьютере

Нужен Node.js 24 или новее. Выполните `npm ci`, затем `npm start`, либо откройте `Start Forma.cmd`. По умолчанию сайт доступен на http://127.0.0.1:3003.

Регистрация требует только логин и пароль. Почта и отдельное имя не нужны. Логин: 3–32 символа, буквы (включая кириллицу), цифры, точки, дефисы и подчёркивания; регистр не важен. Пароль: 12–128 символов. Регистрация, вход и выход работают через сервер. Пароли хешируются scrypt с индивидуальной солью; браузер получает HttpOnly cookie. Локальная база аккаунтов — `data/accounts.sqlite`. Скопируйте эту папку, если переносите локальный сервер. При обновлении старый столбец email автоматически переименовывается в username, сохраняя аккаунты и сессии.

История чатов, настройки провайдеров и вложения хранятся в браузере отдельно для каждого аккаунта. Синхронизации чатов между устройствами нет. Существовавшая до регистрации история остаётся в старом локальном хранилище и автоматически не импортируется. Не очищайте данные старого адреса; сначала экспортируйте нужные чаты из прежней версии. Отдельные аккаунты разделяют интерфейс и хранилище приложения, но не защищают от человека с доступом к файлам профиля браузера.

## Бесплатный Render

1. Загрузите исходники в Git-репозиторий. GitHub не обязателен: Render поддерживает GitLab, Bitbucket, публичный Git URL и готовый Docker-образ. Прямая загрузка папки с компьютера не поддерживается.
2. Подключите постоянную PostgreSQL-базу, например Neon Free. Нужна строка подключения с TLS (`sslmode=require`). Бесплатная Render Postgres имеет ограниченный срок жизни; она не подходит для постоянных аккаунтов без последующего переноса.
3. На Render создайте **Web Service**, выберите репозиторий и **Node**. Build: `npm ci`. Start: `npm start`. Instance: **Free**. Health Check: `/api/health`.
4. Добавьте переменные `NODE_ENV=production`, `NODE_VERSION=24.11.1`, `DATABASE_URL=<строка подключения к PostgreSQL>`. Render автоматически задаёт `PORT` и `RENDER_EXTERNAL_URL`. Таблицы создаются при запуске.
5. Дождитесь успешного деплоя, откройте адрес `https://…onrender.com` и создайте личный аккаунт. Приложение намеренно не запускается в production без внешней базы, чтобы аккаунты не исчезли вместе с временным диском.

В корне уже есть `render.yaml`. Можно использовать Render Blueprint, указав `DATABASE_URL`. Вариант без Git-провайдера: соберите образ по `Dockerfile`, загрузите в доступный Docker registry и на Render выберите **Existing Image**. Сам Dockerfile готовым образом не является.

Бесплатный сервер может засыпать; первый запрос после простоя потребует времени. Хостинг сайта и оплата запросов к AI-провайдерам — разные вещи: модели используют ключи и баланс пользователя. На хостинге разрешены только публичные HTTPS API. Ollama на компьютере доступна локальной версии Forma.

## AgentRouter

В зависимостях закреплён официальный клиент `@openai/codex` 0.167.2, который устанавливается и на Linux. Для каждого запроса создаётся отдельная временная среда. Инструменты отключены; запрос содержит переписку сайта и настройки модели. На Windows по возможности используется уже установленный Codex. Секреты не входят в команды, репозиторий и архив.

Работа из сети Render зависит также от разрешений и лимитов AgentRouter. Локальные тесты транспорта не подтверждают доступность AgentRouter с IP хостинга.

## Ограничения аккаунтов

Восстановление пароля пока не реализовано. Используйте уникальный пароль для Forma и сохраните его у себя. Ограничение попыток входа применяется на сервере; при его перезапуске счётчик сбрасывается.

## Проверка

`npm test` проверяет регистрацию, вход, сохранение после перезапуска, отзыв сессий, защиту API, публичные адреса провайдеров и существующие варианты передачи сообщений, вложений и настроек моделей.
